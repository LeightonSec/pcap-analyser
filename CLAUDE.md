# CLAUDE.md — PCAP Analyser

## What This Is
A Flask web application that analyses PCAP network capture files for 
malicious traffic patterns. Five detection engines identify DoS/DDoS, 
SYN floods, port scans, ARP spoofing and C2 beaconing. AbuseIPDB 
integration enriches findings with real-time threat intelligence.
Built as part of the LeightonSec SOC Toolkit.

## SOC Toolkit Position
- **Layer:** Detection
- **Receives from:** PCAP files captured via Wireshark/tcpdump
- **Feeds into:** Future Incident Tracker (response layer), future Unified Dashboard
- **Alongside:** Log Analyser (security-toolkit) — both in Detection layer
- **Gap it fills:** Network packet level threat detection

## Architecture
- `app.py` — Flask server, file upload handling, secure filename, 50MB limit
- `analyser.py` — Core detection engine, 5 detectors, PyShark parsing
- `threat_intel.py` — AbuseIPDB API integration, IP reputation, caching
- `generate_test_pcaps.py` — Scapy based test PCAP generator, 5 attack types
- `templates/index.html` — Web interface, drag and drop upload, results dashboard
- `uploads/` — Temporary upload storage (gitignored, files deleted post-analysis)
- `reports/` — JSON report storage (gitignored)

## Known Issues / Gotchas
- Beaconing detector requires `avg_interval > 1.0` to avoid false positives on rapid connections
- AbuseIPDB cache is in-memory only — resets on restart
- PyShark requires tshark installed (`brew install wireshark`)
- Test PCAPs generated by scapy — run `generate_test_pcaps.py` to regenerate
- Uploaded files owned by root if captured with sudo — fix with `sudo chown leighton filename.pcap`

## Security Rules
- ABUSEIPDB_API_KEY in .env — never committed
- uploads/, reports/, *.pcap all gitignored
- secure_filename() on all uploads
- File extension whitelist — .pcap, .pcapng, .cap only
- 50MB upload limit
- Files deleted after analysis
- Server bound to 127.0.0.1 only
- Private IPs skipped for AbuseIPDB checks

## Conventions
- All detection logic in analyser.py
- Thresholds in THRESHOLDS dict — adjust there not inline
- Threat intel always via threat_intel.py, never direct API calls in other files
- Severity always strings: "HIGH", "MEDIUM", "LOW"
- Never commit PCAP files — they contain sensitive network data
